A one-image summary of Monday 23 November 2026's world news, drawn as a
newspaper front page. Lead story: COP31 collapses in Antalya with no deal —
the longest COP ever, and the first major COP failure since Copenhagen 2009.
Also covered: the escalating war around the Strait of Hormuz, a Russian drone
strike on the Kyiv region (14 missing), a deadly candy-factory fire in
Indonesia, and the Democrats' historic US House majority.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png (1024x1024, under 1 MiB)
```

`main.py` (stdlib only) copies the pre-rendered `entry.png` in this
repository byte-for-byte to the output directory. No network access.
